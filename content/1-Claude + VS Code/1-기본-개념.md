# 1. 기본 개념

## 1. 클로드코드가 뭐예요?

**한 줄 요약**: 내 컴퓨터에서 일을 직접 해주는 똑똑한 **AI 비서**예요.

### 평소 쓰는 AI랑 뭐가 달라요?

| | 일반 AI 채팅 (ChatGPT, claude.ai) | **클로드코드** |
|---|---|---|
| 어디서 만나요? | 웹사이트 채팅창 | 내 컴퓨터 안 |
| 뭐 할 수 있어요? | 글로 알려주기만 | 진짜 일을 직접 해줘요 |
| 비유 | 전화 상담원 | 내 책상 옆에 앉은 비서 |

### 클로드코드는 뭘 할 수 있어요?

- 📄 **파일 만들기** — 글, 코드, 표 같은 거
- 🔧 **파일 고치기** — 오타 수정, 내용 바꾸기
- 🔍 **파일 찾아보기** — "이 폴더에 뭐 있어?" 같은 질문
- ⚙️ **명령어 실행하기** — 사진 정리, 데이터 옮기기 등 컴퓨터 일

그리고 위 모든 걸 **그냥 말로 시키면** 알아서 해줘요. 코딩을 몰라도 됩니다!

> 💡 한 줄로 다시: **"말로 시키면 컴퓨터 일을 대신 해주는 AI 비서"** — 그게 클로드코드예요.

## 2. VS code는 왜 써야해요?

**한 줄 요약**: 클로드코드(AI 비서)랑 같이 일하기 가장 편한 **작업실**이 VS Code예요.

### VS Code가 편한 3가지 이유

1. **클로드코드(AI)랑 같은 화면에서 일할 수 있어요**
   화면 오른쪽에 클로드 채팅창이 항상 켜져있어서, 궁금한 거 바로바로 물어볼 수 있어요.

2. **파일과 폴더를 한눈에 봐요**
   왼쪽에 폴더 목록이 쭉 떠 있어서, 어떤 파일이 어디 있는지 헤매지 않아요.

3. **명령어 창(터미널)이 같이 있어요**
   `claude` 같은 명령어를 입력할 수 있는 검은 창이 VS Code 안에 있어서, 다른 프로그램을 따로 열 필요가 없어요.

> 💡 **비유로 정리**:
> - VS Code = **책상**
> - 클로드코드 = 책상 옆에 앉아있는 **똑똑한 비서**
> - 우리는 VS Code라는 책상에서 Claude Code라는 비서와 함께 작업물을 만들어요.

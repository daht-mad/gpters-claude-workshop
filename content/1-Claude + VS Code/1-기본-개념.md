## 2. VS code는 왜 써야해요?

**한 줄 요약**: 클로드코드(AI 비서)랑 같이 일하기 가장 편한 **작업실**이 VS Code예요.

### 비유로 이해하기

글을 쓸 때를 떠올려볼까요?

- 메모장에 쓰면 — 글자 색·크기 같은 거 못 바꿈, 정렬도 안 됨, 그냥 글자만 적힘
- 한글이나 Word에 쓰면 — 글자 꾸미고, 표 넣고, 그림 붙이고 편함

**코드도 똑같아요.** 코드를 메모장에 써도 되긴 하지만, 그럼 너무 불편해요. 그래서 코드 쓰기 좋게 만들어진 게 **VS Code**예요.

### VS Code가 편한 3가지 이유

1. **클로드코드(AI)랑 같은 화면에서 일할 수 있어요**
   화면 오른쪽에 클로드 채팅창이 항상 켜져있어서, 궁금한 거 바로바로 물어볼 수 있어요.

2. **파일과 폴더를 한눈에 봐요**
   왼쪽에 폴더 목록이 쭉 떠 있어서, 어떤 파일이 어디 있는지 헤매지 않아요.

3. **명령어 창(터미널)이 같이 있어요**
   `claude` 같은 명령어를 입력할 수 있는 검은 창이 VS Code 안에 있어서, 다른 프로그램을 따로 열 필요가 없어요.

> 💡 **비유로 정리**:
> - VS Code = **책상**
> - 클로드코드 = 책상 옆에 앉아있는 **똑똑한 비서**
> - 책상이 없으면 비서가 어디서 일할까요? 우리도 어디서 작업할까요?

## 3. VS code 쉽게 보기

처음 VS Code를 열면 화면이 복잡해 보일 수 있어요. 하지만 사실은 **4개 영역**만 기억하면 끝!

### 화면 4개 영역

```
┌───────────────────────────────────────────────────────┐
│ 📁 왼쪽 사이드바       │  📝 가운데 (코드 작성 영역)   │
│  (폴더·파일 목록)      │                              │
│                       │                              │
│                       │                              │
│                       ├───────────────────────────────┤
│                       │  💬 오른쪽 (클로드 채팅)      │
│                       ├───────────────────────────────┤
│                       │  ⌨️ 아래쪽 (터미널)           │
└───────────────────────────────────────────────────────┘
```

| 영역 | 역할 | 비유 |
|------|------|------|
| 📁 **왼쪽 사이드바** | 폴더·파일 목록 보기 | 책장 |
| 📝 **가운데** | 실제로 코드를 쓰는 곳 | 책상 위에 펼친 종이 |
| ⌨️ **아래쪽 터미널** | 명령어를 입력하는 검은 창 | 비서한테 말 거는 인터폰 |
| 💬 **오른쪽 패널** | 클로드코드랑 채팅하는 곳 | 비서랑 대화하는 메신저 |

### 처음엔 이렇게만 기억하세요

- **파일 보고 싶다** → 왼쪽 사이드바 (📁 아이콘 클릭)
- **코드 쓰고 싶다** → 가운데 빈 곳
- **명령어 치고 싶다** → 아래쪽 터미널
- **클로드한테 물어보고 싶다** → 오른쪽 채팅창 (주황색 클로드 아이콘 클릭)

> 💡 처음엔 4개 영역이 다 안 보일 수도 있어요. 사이드바·터미널·채팅창은 **각각 열고 닫을 수 있어요**. 필요한 것만 켜놓고 쓰면 돼요.

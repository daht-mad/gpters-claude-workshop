# 0. 사전 확인

## 1. Claude 계정 & Pro 구독

> 💡 Claude Code는 **유료 구독자만** 사용 가능합니다. **Pro($20/월) 이상**이 필수예요.

1. [claude.ai](https://claude.ai) 접속
2. 계정 생성 후 **Pro 구독** ($20/월)

> ⚠️ Free 플랜으로는 Claude Code를 쓸 수 없습니다. 결제 전에 무료 체험으로 먼저 채팅 UI를 써보시고, 마음에 들면 Pro로 업그레이드하세요.

## 2. VS Code 설치

> 💡 이미 **Cursor** 또는 **Antigravity** 쓰시는 분은 이 단계 건너뛰세요!
